# Bac Story — DriveSystem.js — Google Drive Viewer

- What is this?
DriveSystem.js is a lightweight JavaScript module built for Bac Story website. It intercepts Google Drive links and opens them inside an in-page overlay (modal) instead of redirecting the user to a new tab or a separate page.

- Why was it built?
The main problem it solves is user retention. When students click a Google Drive link (a lesson, a document, a folder), they get taken out of the website. Getting them back requires them to manually navigate back — and most of the time, they just don't.
This system keeps the student inside the website the whole time, which:

- Improves the overall user experience significantly
- Reduces bounce rate
- Keeps the student focused without losing context

The idea was inspired by csbouira website, which uses a similar embedded viewer approach. The goal was to bring the same quality of experience to Bac Story.
